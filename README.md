# MWIKI Modern Health Centre Website

A professional, modern website for MWIKI Modern Health Centre featuring a multi-page design with healthcare services and patient engagement features.

## Website Features

### Pages
- **Home Page** - Featuring an image slideshow, sticky FAQ and reviews sections, and CTA buttons
- **Services Page** - Comprehensive list of healthcare services offered
- **About Page** - Information about the health centre, mission, vision, values, and team
- **Contact Page** - Contact form, appointment booking options, and interactive map

### Key Features

1. **Background Image** - Full background image using background-image.png
2. **Logo Integration** - Logo image (logo.png) next to the text logo "mwiki modern medical centre"
3. **Responsive Design** - Fully responsive on desktop, tablet, and mobile devices
4. **Glass Effect Headings** - Modern H1 and H2 headings with glass morphism effect
5. **Azure Blue Navigation** - Professional navigation bar with CTA buttons
6. **Image Slideshow** - Auto-rotating slideshow with manual controls
7. **Sticky Sections** - FAQ and reviews sections for easy access to information
8. **CTA Buttons**
   - Appointment booking button in navigation bar (direct phone call)
   - WhatsApp chat button (fixed position, small size)
9. **Contact Information**
   - Email: mwikimodern@gmail.com
   - Phone: +254 748 662082
   - Address: 6 Red Soil St, Nairobi
   - WhatsApp integration for direct messaging
10. **Social Media Links**
    - Facebook embedded post
    - Instagram location page
11. **Elementor-Style About Page** - Azure blue theme with full-width sections
12. **Interactive Google Maps** - Specific location integration

### Technical Details

- **HTML5** - Semantic markup for better accessibility
- **CSS3** - Modern styling with glass effect, gradients, and animations
- **Vanilla JavaScript** - No dependencies, lightweight functionality
- **Font Awesome Icons** - Professional icons for services and features

## How to Use

1. **Open in Browser** - Simply open `index.html` in any modern web browser
2. **Navigate** - Use the navigation bar to move between pages
3. **Book Appointment** - Click the "Book Appointment" button or use contact page
4. **WhatsApp Chat** - Click the floating WhatsApp button to start a conversation
5. **FAQ** - Expand FAQ items on the home page to get answers to common questions
6. **Reviews** - Check patient reviews on the home page

## Customization

### Add Logo
- Place your logo image as `images/logo.png`
- The logo will appear next to the text in the navigation bar

### Change Contact Information
- Update email in all HTML files: Search for `mwikimodern@gmail.com` and replace
- Update phone in all HTML files: Search for `+254748662082` and replace
- Update address: Search for `6 Red Soil St, Nairobi` and replace

### Change Colors
- **Primary Color (Azure Blue)**: Look for `#0078d4` in `style.css`
- **Accent Color (Red)**: Look for `#ff6b6b` in `style.css`
- **Text Color**: Look for `#333` in `style.css`

### Replace Images
- Replace slideshow images in the `images/` folder:
  - `w1.jpeg` - First slide
  - `w2.jpeg` - Second slide
  - `w3.png` - Third slide
- Replace background image: `background-image.png`

### Update Social Media Links
- Facebook: Update the iframe src in footer sections
- Instagram: Update the href in footer sections
